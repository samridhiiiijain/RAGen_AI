API Limits

The AcmeOps public API uses API keys scoped to one workspace. Starter workspaces can make 120 requests per minute. Growth workspaces can make 600 requests per minute. Enterprise workspaces can negotiate a custom limit.

Bulk export jobs are limited to three concurrent jobs per workspace. Export links expire after 48 hours.
